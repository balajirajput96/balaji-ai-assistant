# Changelog

## 0.1.0 — First local foundation

The first foundation adds local assistant request capture, task tracking, research draft storage, automation readiness recording, five-tab navigation, privacy reset controls, status-only document/memory/connector/usage surfaces, a dedicated brand palette, domain tests, and source-backed architecture/security/privacy documentation.

No external model, connector, scheduler, deployment, or Play Store submission is included in this version.
