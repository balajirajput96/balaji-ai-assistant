# Privacy Summary

## Current Foundation

Assistant messages, local task records, saved research questions, and automation blocker notes are stored on the device through local app storage. The current UI does not send these records to an AI provider, research source, document processor, connector, cloud database, or social platform.

## Controls

The Settings screen includes a destructive confirmation to delete the stored assistant snapshot. Future cloud sync, document upload, voice processing, provider use, or connected-tool access must update this document, the in-app disclosure, and the release Data safety declaration before being enabled.

No production privacy policy URL has been published. No Play submission has been made.
